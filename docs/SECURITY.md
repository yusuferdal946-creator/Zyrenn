# Güvenlik modeli (v0.3.0) — KOD YAZILDI, cihazda test edilmedi

## Ne korunuyor, nasıl
| Alan | Önlem | Sınır / dürüst not |
|---|---|---|
| Dosya erişimi | Tüm yollar `PathGuard`'dan geçer: `../`, mutlak yol, sembolik bağ, önek hilesi engelli. Araçlar `.zyren/` (planlar, kurallar, durum) klasörüne yazamaz | Zyren yalnızca kendi çalışma klasörünü görür; telefonun diğer dosyalarına erişimi yoktur |
| Terminal | **Güvenli terminal** süreç başlatmaz; yalnızca yerleşik komutlar (ls, cat, grep, find, mkdir, touch, cp, mv, rm…), yalnızca çalışma klasöründe; boru/yönlendirme/değişken/komut ikamesi yok; `mv/cp` üzerine yazmaz; `rm` çöp kutusuna taşır ve onay ister | Gerçek izolasyon budur çünkü kabuk yoktur |
| Ham kabuk | Varsayılan KAPALI, her çalıştırmada onay, ortam temizlenir, 30 sn sınır | **Android'de uygulama içi gerçek izolasyon yoktur.** Ham kabuk Zyren'in kendi Linux kullanıcısıyla çalışır; uygulamanın özel verilerine (veritabanı, şifreli anahtarlar) ve ağa erişebilir. Önerilmez |
| JavaScript | Rhino yorumlayıcı modu, ayrı iş parçacığı, süre (3 sn, talimat sayacı), yığın derinliği, bellek artışı, çıktı sınırı; Java sınıflarına erişim yok; betikteki `try/catch` zaman aşımını yakalayamaz | Aşırı bellek tahsisi nadiren yine de `OutOfMemoryError` verebilir (yakalanır); takılırsa motor kilitlenir ve yeniden başlatma ister |
| ZIP geri yükleme | Önce güvenlik yedeği; ZIP **geçici dizine** açılır (yol kaçışı, mutlak/ters eğik çizgi, girdi sayısı ≤20.000, toplam ≤800 MB, girdi ≤300 MB); başarılıysa çalışma alanı değiştirilir. Açma başarısızsa çalışma alanına dokunulmaz | İçe aktarılan paket güvenilmeyen veri sayılır ama içeriği (planlar, kurallar) sonradan doğrulanmaz |
| API anahtarı | Android Keystore AES-256-GCM (anahtar dışarı çıkmaz), şifreli metin sağlayıcıya bağlı (AAD); çözme hatasında çökmez; günlüğe/dosyaya yazılmaz; `allowBackup=false` + veri çıkarma kuralları ile bulut/cihaz aktarımı dışı | Root'lu/ele geçirilmiş cihazda koruma sınırlıdır |
| Kullanıcı verisi | Hafıza/sohbet/planlar yalnızca cihazda. **Şifreli dışa/içe aktarma:** AES-256-GCM, parçalı (64 KB) ve her parça sıra+"son parça" bayrağıyla doğrulanır → kurcalama, parça silme/yer değiştirme, kesme tespit edilir. Anahtar PBKDF2-HMAC-SHA256 (200.000 tur, rastgele tuz) ile **kullanıcı parolasından** türetilir; parola ve anahtar **hiçbir yerde saklanmaz**, kullanımdan sonra bellekten silinir; ≥10 karakter, yalnız rakam olamaz | Parola kaybolursa paket **kurtarılamaz** (bilinçli). "ZIP dışa aktar (ŞİFRESİZ)" seçeneği hâlâ var ve etiketli. Kotlin `String` parola nesnesi UI katmanında silinemez (CharArray kopyası silinir) |
| Ağ | `usesCleartextTraffic` KAPATILDI. Ağ güvenlik yapılandırması: açık metin (http) varsayılan yasak, yalnızca sistem sertifikaları; tek istisna aynı telefondaki `127.0.0.1`/`localhost` (llama.cpp vb.). İstemci kodu aynı listeyi ayrıca uygular; web sayfası okuma yalnızca https | LAN/PC sunucusu http ile **çalışmaz** (CIDR/joker desteklenmiyor); https gerekir |
| Onay mekanizması | Kritik yetkiler `PermissionManager.check` içinde onay işleyicisi olmadan **reddedilir**; onay penceresi sıraya alınır (aynı anda tek pencere) ve 120 sn yanıtsız kalırsa REDDEDİLİR; onay işleyicisi yalnızca arayüzde atanabilir (CI betiği doğrular) | Cihazda doğrulanmadı |
| Merkezi izin | Her araç `PermissionManager`'dan geçer: izin açık mı → kilit modu → kritikse kullanıcı onayı → denetim kaydı. İlk açılışta izin seçim ekranı; riskli/hassas olanlar KAPALI başlar | Android çalışma-zamanı izinleri ayrıca istenir |
| Şüpheli işlem | `AnomalyDetector`: 1 dk'da >8 kritik istek, >12 ret veya >60 işlem → **kilit modu** (riskli işlemler durur, yalnızca kullanıcı kaldırır) | Eşikler sezgiseldir, gerçek kullanımla ayarlanmalı |
| Kendi güvenliğini kapatamama | Araçlar/ajanlar `PermissionManager`'a erişemez; izinleri yalnızca arayüz değiştirir; kritik işlemler onay penceresi olmadan reddedilir; özel araçlar saf JS'tir | Mimari garantidir; cihaz testi bekliyor |
| Arka plan | Yalnızca izin listesindeki güvenli araçlar; kritik olanlar atlanır; duraklatma, kilit modu ve AUTOMATION_RUN izni denetlenir; 5 art arda hata → kural durur | WorkManager ≥15 dk, tam zamanlı değildir |
| Eklentiler | Yalnızca yerleşik eklentiler; her biri bildirdiği yetkilerle sınırlı; aç/kapat. **Harici eklenti yükleyici yok** (bilinçli) | Üçüncü taraf eklenti ekosistemi yok |
| Web içeriği | "Güvenilmez veri" etiketi; ajan sistem istemi talimat izlememeyi söyler; kritik eylemler yine onaylı | Prompt injection tamamen çözülmüş değildir; asıl koruma onay + izin hattıdır |
